# ROADMAP.MD — Prioridades ABCD para el rediseño de De Gante

## Regla general
No rehacer todo a la vez.
Se construye por capas, en orden de impacto.

El orden correcto es:
- **A = posicionamiento y estructura crítica**
- **B = sistema visual y componentes clave**
- **C = profundidad de prueba, contenido y optimización**
- **D = polish, escalamiento y extras**

---

# A — Crítico / impacto máximo / primero

## Objetivo
Definir la columna vertebral del sitio.
Sin esto, todo lo demás será cosmética.

## A1. Reposicionamiento del homepage
### Entregable
- mensaje central definitivo
- promesa principal
- categoría propia
- criterio para prospecto ideal

### Resultado esperado
Que el sitio deje de sonar a “desarrollo web” y suene a “infraestructura para destrabar crecimiento”.

## A2. Arquitectura narrativa completa
### Entregable
Orden definitivo del homepage:
1. Hero
2. Cambio de paradigma
3. Diagnóstico
4. Arquitectura de crecimiento
5. Casos
6. Proceso
7. Escasez / CTA final

### Resultado esperado
Que el sitio tenga columna vertebral comercial.

## A3. Hero final de calidad producción
### Entregable
- Hero reescrito desde cero
- composición de dos columnas real
- copy definitivo
- CTA principal y secundario
- franja de autoridad
- protagonista visual claro

### Criterio de aprobado
Si el hero no se siente premium, humano y vendedor, no se avanza.

## A4. Sistema base de copy
### Entregable
- headline matrix
- reglas de tono
- vocabulario permitido
- vocabulario prohibido
- CTA system

### Resultado esperado
Consistencia total de voz.

## A5. Navegación y estructura de información
### Entregable
- navbar definitiva
- arquitectura de páginas
- rutas y anchors principales

### Resultado esperado
Navegación clara, corta y premium.

---

# B — Importante / diseño y conversión visible

## Objetivo
Convertir la estrategia en interfaz seria.

## B1. Design system base
### Entregable
- tokens de color
- escala tipográfica
- espaciado
- radios
- sombras
- layout containers
- grid rules

## B2. Componentes fundacionales
### Entregable
- Button
- SectionHeader
- ProofCard
- MetricStrip
- ProcessStep
- CTASection
- QuestionCard / DiagnosticOption

## B3. Sección “Cambio de paradigma”
### Entregable
Bloque premium con:
- problema
- costo
- solución

## B4. Sección de diagnóstico
### Entregable
- 3 a 5 preguntas
- barra de progreso
- estados y resultados
- CTA condicional

## B5. Sección “No vendo servicios sueltos”
### Entregable
Bloque arquitectura de crecimiento con 5 pilares:
- Captación
- Calificación
- Seguimiento
- Operación
- IA aplicada

## B6. Casos / prueba social
### Entregable
Grid editorial premium para casos.

## B7. Proceso
### Entregable
Paso a paso visual elegante:
- Diagnóstico
- Estrategia
- Sistema
- Implementación
- Optimización

---

# C — Valioso / prueba profunda / cierre fino

## Objetivo
Profundizar autoridad y elevar precio percibido.

## C1. Páginas de caso
### Entregable
Landings individuales para:
- Visor Urbano
- Joya Studio
- SaaS veterinario / Pawfect
- otros proyectos ancla

## C2. Página Sobre mí
### Entregable
- narrativa profesional
- trayectoria
- visión
- diferenciadores
- autoridad institucional y comercial

## C3. Página de diagnóstico
### Entregable
Versión completa y autónoma del filtro.

## C4. Página de agenda / consultoría
### Entregable
- pre-frame comercial
- criterios para agendar
- qué esperar de la llamada
- CTA de cierre

## C5. Microcopy y refinamiento de UX
### Entregable
- estados vacíos
- mensajes de formulario
- confirmaciones
- hover states
- tooltips si hacen falta

## C6. SEO base de marca
### Entregable
- titles
- descriptions
- H structure
- schema básico si aplica
- copy orientado a búsquedas correctas

---

# D — Opcional / polish / expansión

## Objetivo
Mejorar experiencia, performance y escalabilidad.

## D1. Animación premium
### Entregable
- motion sutil
- entrances coherentes
- hover intelligence
- scroll reveals con moderación

## D2. Performance
### Entregable
- optimización de imágenes
- lazy loading correcto
- limpieza de DOM y CSS
- revisión Core Web Vitals

## D3. Recursos descargables
### Entregable
- mini guía
- checklist de diagnóstico
- auditoría ligera

## D4. Integraciones
### Entregable
- agenda
- tracking
- analítica
- eventos de conversión

## D5. Experimentos CRO
### Entregable
- variantes de hero
- tests de CTA
- pruebas de caso principal
- tests de orden de secciones

# Matriz de prioridad real

## Qué NO puedes delegar ciegamente a Codex
- posicionamiento
- copy núcleo
- dirección de arte
- jerarquía
- story spine
- selección de casos

## Qué SÍ puede ejecutar Codex bien si le das sistema
- componentes
- layout
- responsive
- refactors
- integración visual
- animación sutil
- limpieza del código

---

# Definición de terminado

Un bloque se considera terminado solo si cumple estas 5:
1. se ve premium
2. comunica una idea comercial clara
3. tiene jerarquía
4. tiene un siguiente paso
5. no parece template

# Asignación directa

Antes de rehacer más secciones, termina esto en orden:

## Orden exacto
1. Hero
2. Cambio de paradigma
3. Diagnóstico
4. Arquitectura de crecimiento

7. CTA final
